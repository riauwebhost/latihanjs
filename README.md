# Latihan JS — README Keren

> Koleksi latihan JavaScript ringkas, terstruktur, dan siap dicoba.

✨ Fitur utama

- Contoh kode praktis dan modular
- Skrip npm untuk build, test, dan run
- Struktur folder sederhana untuk belajar cepat

## Demo singkat

Jalankan project lokal:

```bash
git clone <repo-url>
cd project
npm install
npm start
```

## Instalasi

1. Pastikan Node.js terpasang (v14+ direkomendasikan)
2. Install dependensi:

```bash
npm install
```

## Penggunaan

- Jalankan aplikasi:
  ```bash
  npm start
  ```
- Jalankan tes:
  ```bash
  npm test
  ```

## Struktur proyek

- src/ — kode sumber latihan
- tests/ — unit test
- examples/ — contoh penggunaan
- README.md — dokumentasi ini

## Cara kontribusi

1. Fork repo
2. Buat branch fitur: `git checkout -b feat/nama-fitur`
3. Commit dan push: `git push origin feat/nama-fitur`
4. Buka Pull Request dengan deskripsi singkat

## Lisensi

Gunakan sesuai kebutuhan pribadi atau edukasi. Tambahkan lisensi jika ingin publik.

Butuh fitur atau contoh tertentu? Tambahkan permintaan spesifik di issues.
